# Rachit Garg — Resume Website
> My personal resume and portfolio website, built to showcase my skills, education, projects, experience, and achievements.

🌐 **Live Website:** [rachitvoid.github.io/Rachit_resume](https://rachitvoid.github.io/Rachit_resume/)

---

## 📌 About the Project

This is my **first personal web development project** — a responsive online version of my resume.

The goal of this project is to present my professional profile in a clean, accessible, and easy-to-navigate format while also demonstrating my understanding of web development and GitHub.

Instead of sharing only a traditional PDF resume, this project provides an interactive way to explore my background and work.

---

## ✨ Features

* 📄 Online version of my resume
* 👨‍💻 About Me section
* 🎓 Education and academic background
* 💼 Experience and achievements
* 🛠️ Technical skills
* 🚀 Projects and work
* 📱 Responsive design
* 🔗 Links to my professional profiles
* 🌐 Hosted using GitHub Pages

---

## 🛠️ Technologies Used

* **HTML5** — Structure and content
* **CSS3** — Styling and responsive design
* **JavaScript** — Interactivity
* **Git & GitHub** — Version control and hosting
* **GitHub Pages** — Deployment

## 🚀 Getting Started

To run the project locally:

```bash
# Clone the repository
git clone https://github.com/rachitvoid/Rachit_resume.git

# Navigate to the project
cd Rachit_resume

# Open index.html in your browser
```

No additional dependencies or installation are required.
